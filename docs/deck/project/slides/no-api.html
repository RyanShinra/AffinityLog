The constraint

The source has no API

I knew I couldn't discover a drug in 30 days. But Bio Discovery doesn't offer any data storage, so everybody who uses it needs to make their own database. That is what this is. Bio Discovery is UI only, with no REST, no SDK and no boto3, so all the data in the store was imported via a CSV file exported from the experiments.

Loading is a script I run

Every loader is idempotent, so re-running one converges instead of duplicating. Reloading the same export is the normal case here, not an error.

The columns aren't knowable in advance

Each pipeline emits its own. Seven CSV files gave me 200 distinct keys, so a fixed schema is completely untenable.

Nothing upstream explains a column

There's no service to ask what a header means, so I had to store the meaning next to the data myself.
