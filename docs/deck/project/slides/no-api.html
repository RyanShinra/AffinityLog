The constraint

The source has no API

Amazon Bio Discovery — AWS's computational antibody-engineering platform, demoed at the June 2026 AWS Summit — is UI-only. No REST, no SDK, no boto3. Every row in this database entered it as a CSV file a person exported by hand.

Ingestion is a script, not an endpoint

Every loader is idempotent and converges on a re-run, because reloading the same export is the normal case rather than an error.

The columns are not knowable in advance

Each pipeline emits its own, so a fixed schema is wrong on arrival. Seven CSV files produced 200 distinct keys.

Nothing upstream will explain a column

There is no service to ask what a header means. The meaning has to be stored beside the data, by hand, once.
