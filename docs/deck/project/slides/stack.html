How it runs

The stack, briefly

API

FastAPI · Strawberry GraphQL, code-first · one AsyncSession per request, shared by the whole resolver tree

Data

SQLAlchemy 2.0 async · asyncpg · PostgreSQL 16 · Alembic, migrations 001 through 008

Tests

pytest · pytest-asyncio · testcontainers running the same postgres:16-alpine image as compose · 236 passing

Gates

ruff · black · mypy strict over the whole tree, not just the app · GitHub Actions: lint, test, build

Two heads on one app, on purpose. REST takes the CSV upload, because Strawberry has no multipart upload without tooling I chose not to add for a single endpoint. GraphQL takes everything else.
