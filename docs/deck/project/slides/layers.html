The schema

Three layers

1 · The bag

candidates.scores

JSONB, GIN-indexed, keyed by the full export header, values stored as uncoerced text. A new recipe needs no migration.

2 · The chains

candidate_chains

Zero or more rows per candidate — HEAVY, LIGHT, TARGET — with their sequences. Chain composition is what disambiguates the bag.

3 · The catalog

modules / metrics / concepts

What a score means: display name, unit, direction, value type, and the caveat that has to travel with the number.

Each layer answers a question the one before it cannot. The bag absorbs whatever a pipeline emits, but cannot say what a column is. The chains say what was folded, but not what to call it.
