Resolving a key

The two-tier lookup

Tier one

Does the key identify a metric by itself?

True for 197 of the 200 keys. One lookup, no candidate context required.

Tier two

Supply the candidate's interface kind.

For the three INTERFACE-qualified headings, chain composition completes the identity.

Asked in that order, rather than looked up and retried on a miss. Retry-on-miss happens to work today only because of how the seeder skips rows.

Metric identity is (module, column_key, variant_kind, variant). Three columns — iptm, protein_iptm, complex_ipde — times three interface kinds gives nine catalog rows for what looks like three columns.
