Humanization is meant to lower the chance a patient's immune system attacks the drug itself. These two runs show what it changed. Neither of them scores humanness, because both are Boltz2 alone, so the benefit is measured elsewhere, under BioPhi and Humatch.

ipTM is the model grading its own geometry. Boltz-2 does predict binding affinity, but only for a small molecule against a protein target, so for an antibody there is no binding number to be had and this is the proxy the field reaches for. On a three-chain fold it is averaged across all three interfaces, so part of that −0.091 is the heavy–light pairing rather than the grip on HER2.

On the developability side the manifest records every ESM2 predicted property moving less than 0.05, except light-chain thermal stability, which moved −0.16.
